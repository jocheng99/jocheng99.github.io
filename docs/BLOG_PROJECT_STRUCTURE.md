# CoolCheng Blog Project Structure

This document is the blog-specific layer on top of the project entry rules in `AGENTS.md`, `START_HERE.md`, and `PROJECT_STRUCTURE.md`.

## Top-Level Layout

```text
archive/                 Read-only archive unless explicitly requested
config/                  Blog configuration examples and local templates
docs/                    Project documentation and deployment notes
reference_materials/     External references, legacy static site, and notes
research/                Blog platform experiments and feature validation
results/                 Reports or long-term visual QA artifacts
skills/                  Project-local workflow skills
src/                     Astro source, content, layouts, pages, and utilities
public/                  Public static assets copied into the build output
tmp/                     Temporary preview, render, cache, and check files
dist/                    Astro build output, regenerated by build commands
```

## Blog Source Layout

```text
src/content/blog/        Markdown posts managed by Astro Content Collections
src/content.config.ts    Blog content schema and loader
src/components/          Reusable Astro components
src/layouts/             Base and blog post layouts
src/pages/               Astro pages and dynamic routes
src/styles/              Global CSS
src/utils/               Blog data, taxonomy, and base path helpers
src/tools/               Optional reusable build, export, or maintenance scripts
public/assets/           Public images, avatar, covers, favicon, and legacy assets
```

## Output Layout

```text
dist/                    Astro static build output
results/blog/site/       Optional copied publishable site export if needed
results/blog/screenshots/  Final screenshots or visual QA artifacts
results/reports/         Longer project reports, if needed
tmp/blog/render_check/   Temporary screenshots, previews, and render checks
```

## Current Scaffold Decision

The current scaffold is an Astro static blog project with TypeScript, Markdown Content Collections, and Pagefind search. The main commands are:

```text
npm install
npm run build
npm run build:search
```

The default GitHub Pages target is `https://jocheng99.github.io/` with base path `/`, configured in `astro.config.mjs` and overridable with `SITE` and `BASE`.
