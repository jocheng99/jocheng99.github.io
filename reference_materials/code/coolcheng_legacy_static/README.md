- 它不是新博客源码。
- 新博客源码以根目录 Astro 项目为准。
- 旧 HTML/CSS/JS 仅作为历史参考。
- 旧图片素材可复制到 `public/assets/legacy/` 后在新站中使用。
- `image/微信.jpg` 和 `image/支付宝.jpg` 涉及个人收款/联系方式类信息，本次不复制到公开站点资源。
