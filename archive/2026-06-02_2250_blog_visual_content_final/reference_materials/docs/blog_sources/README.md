# Blog Sources

本目录保存已经转化为博客文章的来源材料。`reference_materials/inbox/` 只用于临时存放尚未处理的新资料；资料转成博客后，应移动到这里按文章 slug 分类保存，方便后续回查来源。

如果来源材料包含 Markdown、图片、PPTX 或其他附件，应保持原始文件夹结构整体移动到对应文章 slug 下。公开展示所需图片另复制到 `public/assets/blog/<post-slug>/`，博客正文引用公开资源路径。

当前分类：

```text
ai-research-workflow/                     AI 科研工作流文章来源
generative-ai-prompt-assistant-guide/     生成 AI 提示词助手文章来源
ppt-automation-drawing-workflow/          PPT 自动化绘图文章来源和配图/PPTX
```
