# IEEE Template Workspace

Do not use an unofficial IEEE template from memory.

Workflow:

1. Check `reference_materials/inbox/` for the official IEEE template package or author instructions provided by the user.
2. If missing, ask for confirmation before downloading from the official IEEE author template source.
3. Keep the original template package unchanged under `reference_materials/`.
4. Copy a working version into `research/<topic>/manuscript/`.
5. Compile through `src/tools/build_latex_manuscript.ps1` so build artifacts stay under `tmp/` and final PDFs/logs under `results/`.
