# Source

Stable Astro blog source lives here.

```text
src/components/       Reusable Astro components
src/content/blog/     Markdown posts
src/layouts/          Base and blog post layouts
src/pages/            Static and dynamic routes
src/styles/           Global CSS
src/utils/            Blog data, path, and taxonomy helpers
src/tools/            Optional reusable build or maintenance scripts
```
