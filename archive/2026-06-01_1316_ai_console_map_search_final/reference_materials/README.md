# Reference Materials

Use this area for external materials that inform the blog but are not stable site source.

```text
reference_materials/inbox/  Unprocessed incoming files
reference_materials/docs/   Design notes, writing references, specs, PDFs
reference_materials/docs/blog_sources/  Processed source materials for blog posts
reference_materials/code/   External code, legacy static sites, and old packages kept as reference only
reference_materials/notes/  Source notes and organization records
```

If a blog material arrives as a folder under `inbox/`, treat the whole folder as one article group. After the article is created, move the source materials to `docs/blog_sources/<post-slug>/` so `inbox/` only contains material that still needs processing.
